## 🌟 Featured Projects

### 🚀 MANITPULSE

**AI-Driven University Feedback Platform**

A full-stack anonymous feedback platform built for **MANIT Bhopal students**, leveraging AI for content moderation, categorization, and vector-based duplicate detection.

**Highlights**

* 🤖 AI-powered content moderation and feedback categorization
* 🔍 Vector-based duplicate feedback detection
* 📊 Real-time analytics dashboard
* 📈 Automated sentiment reports and actionable campus insights
* 📄 PDF report generation
* 📧 Automated email notifications

**Tech Stack**

`React.js` `Vite` `Node.js` `Express.js` `MongoDB` `Mongoose` `Google Gemini AI` `Tailwind CSS` `Recharts` `PDFKit` `Nodemailer`

🔗 **[Live Demo](https://manitpulse-omega.vercel.app/)**   |   💻 **[GitHub Repository](https://github.com/Eshwanth13/manitpulse)**

### ⚡ Flow-Q

**Real-Time Queue Management SaaS for Businesses**

A multi-tenant queue management platform that enables businesses to onboard customers instantly through a **zero-install browser link**, eliminating physical waiting lines with live position tracking.

**Highlights**

* 🏢 Multi-tenant architecture for businesses
* ⚡ Real-time queue position tracking
* 🔌 Persistent WebSocket communication using Socket.io
* 🔗 Zero-install customer experience
* 🌐 B2B REST API
* 🪝 Automated webhooks for third-party integrations
* 🚀 Near-instant queue status updates

**Tech Stack**

`Next.js` `Node.js` `Socket.io` `MongoDB` `Mongoose` `Webhooks`

🔗 **[Live Demo](https://flow-q-binary-builders.vercel.app/)**   |   💻 **[GitHub Repository](https://github.com/VaishnavAmbilpur/FLOW-Q_Binary_Builders)**
